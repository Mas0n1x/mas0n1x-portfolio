GitHub Webhook

Automatisch: Trage deinen GitHub Personal Access Token ein und klicke auf "Alle Repos verbinden" um den Webhook automatisch auf allen deinen Repositories einzurichten.
Token erstellen: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → admin:repo_hook Berechtigung

GitHub Organisationen

Füge GitHub Organisationen hinzu, um auch deren Repositories mit Webhooks zu verbinden.
Dein Token benötigt zusätzlich die admin:org_hook Berechtigung für Organisations-Webhooks.

Repo-Auswahl für Discord-Posts

Wähle aus, welche Repositories in den GitHub-Channel gepostet werden. Abgewählte Repos lösen keine Discord-Nachricht aus (die Webhooks bei GitHub bleiben erhalten).
Sind alle Repos ausgewählt, werden automatisch auch neue/zukünftige Repos gepostet.

Ticket-System
